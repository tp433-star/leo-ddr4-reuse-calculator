Positioning brief

Who buys

Hyperscaler and cloud infrastructure teams in the middle of a fleet refresh, where memory is now one of the biggest line items per server.

First objection

"CXL memory is slower than local DRAM." True, so lead with tiering. Hot data stays in native DDR5, warm data like agent context and cached state sits on reused DDR4.

Proof to bring

Their own fleet numbers in this calculator, a latency test on one real workload, and a pilot rack before any fleet-wide decision.
